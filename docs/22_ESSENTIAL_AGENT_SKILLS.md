## ⚡ How to Add Custom Skills to Antigravity

Antigravity loads skills from standard directories. To add any of these skills:

1. **Global User Skills**: Place the skill folder in:
   ```
   ~/.gemini/antigravity/builtin/skills/<skill-name>/SKILL.md
   ```
2. **Project Local Skills**: Place the skill folder in:
   ```
   <repo-root>/.gemini/skills/<skill-name>/SKILL.md
   ```
3. **Format**: Ensure `SKILL.md` begins with YAML frontmatter:
   ```yaml
   ---
   name: skill-name
   description: Brief description of when to activate this skill.
   ---
   ```
